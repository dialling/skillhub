# Hard gates (must pass)

## G1 可卖性（选品）

Fail any → archive with reason, do not source.

- [ ] Not prohibited / counterfeit / needs cert user cannot provide
- [ ] Size/weight suitable for cross-border parcel (flag if volumetric risk)
- [ ] Local fit: voltage/plug/climate/language/habit considered
- [ ] Competitor price band still leaves margin room after freight
- [ ] Demand signal exists (sales velocity, search, or clear local need) — not vanity metrics only

## G2 同款一致（寻源）

Fail any → do not list.

- [ ] Material / dimensions / accessories / color / pack-in match
- [ ] Supplier MOQ and lead time acceptable
- [ ] Backup supplier identified (optional but preferred)

## G3 利润（定价）

```
到岸成本 ≈ 采购 + 运费(表) + 包装 + 平台费预估 + 退货预留 + 汇率缓冲
售价 ≥ 到岸成本 / (1 - 目标毛利率)
售价 对齐竞品价带（过高无转化 / 过低无利润）
```

Fail → change supplier, shrink kit, or kill SKU. **Never guess freight.**

## G4 内容合规（上架）

- [ ] Claims are verifiable (size, material, use scene)
- [ ] No fake badges / fake reviews / unauthorized brand
- [ ] Language matches target market (EN / FR / PT as specified)
- [ ] Lead-time promise is conservative

## G5 履约异常

Escalate to human when: OOS, price spike > threshold, address incomplete, buyer wants refund/dispute, customs hold.
