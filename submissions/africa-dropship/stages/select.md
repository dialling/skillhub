# Stage A — 选品 / 竞品

## Goal

Produce a ranked candidate pool that passes **G1** in [gates.md](../gates.md).

## Steps

1. Lock scope: country, platform, category, price band.
2. Gather signals: recent bestsellers, growth, review themes, search intent (user-provided data preferred over invented stats).
3. Build competitor snapshot per candidate: price, main claims, top complaints, shipping promise.
4. Run **G1 可卖性**. Kill or park failures with one-line reason.
5. Output **候选 SKU 表** from [templates.md](../templates.md).
6. **Human checkpoint:** 选品终审 before sourcing.

## Agent constraints

- Do not fabricate sales numbers or “平台内部数据”. If data is missing, list what to collect next.
- Prefer fewer strong candidates (3–10) over a long unfiltered list.
- Flag Africa-specific fit: plug/voltage, heat/dust, language, payment/logistics reality when relevant.

## Done when

候选表 filled + each row has 推进/观察/淘汰 + G1 pass/fail noted.
