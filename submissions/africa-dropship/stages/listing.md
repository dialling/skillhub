# Stage D — 主图 / 卖点 / 上架

## Goal

Ship an **上架包** that passes **G4**; ready for platform publish.

## Steps

1. Lock language(s) for target market (EN/FR/PT/…).
2. Write title + 3–5 verifiable bullets + short description + specs table.
3. Specify main-image set: white background, lifestyle, dimension diagram, benefit bar — must match sourced product.
4. Fill category/attributes checklist for the user’s platform (ask platform if unknown).
5. Conservative delivery ETA copy.
6. Output **上架包** ([templates.md](../templates.md)).
7. Publish via user’s process (API/manual); record listing id if provided.

## Agent constraints

- No fake certificates, “#1”, medical claims, or brand misuse.
- Selling points must map to real specs from Stage B.
- If generating image prompts: require consistency with real product; note “需人工核对实物”.
- Keep copy scannable; one job per section.

## Done when

上架包 complete + G4 checklist checked; listing id if already published.
